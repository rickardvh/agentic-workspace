# V1 contraction disposition

This is the final disposition map for the surfaces named by the v1 convergence
issues. Counts compare `origin/master` before the contraction with this stacked
release branch.

| Surface | Before | V1 disposition |
| --- | ---: | --- |
| Semantic answer | Purpose-specific packets, posture builders, final-response and continuation peers | One `compile_source_decision` reducer over source-owned contributions |
| Action authority | Command packages, adapter generation, argv reconstruction, and operation catalogues | One typed `Operation` definition and `OperationDispatcher` |
| Public commands | 129 command/subcommand routes | 2: `start` and `invoke` |
| Python distributions | 4 coordinated first-party distributions | 1: `agentic-workspace` |
| First-party extension | Package/runtime symmetry and central registries | 4 logical modules using one entry-point seam; external modules use the same seam |
| Generated tree | 809 tracked files | 0; released Python consumes source contracts directly |
| Sibling package tree | 258 tracked files | 0 |
| Installed host payload | 1,903 tracked `.agentic-workspace` files | 0 generic files; durable state is created only by relevant operations |
| Compatibility | Readers, aliases, migrations, warning projections, and source fallbacks | One bounded `workspace.remove-legacy` operation for recognized managed markers |
| Local continuation | Checkpoints, work threads, carry, capsules, and polling views | Deleted; an operation result embeds the next source-derived decision |
| Checked-in fallback | Operational no-runtime mini-implementation | Deleted; reinstall the current distribution |
| Tracked repository | 4,134 files | 44 files |

The combined stack removes 1,197,937 lines and adds about 1,500 lines before the
release-admission proof. Direct work performs one decision compilation, returns
seven top-level semantic fields plus its schema kind, and writes no durable
state. Actionable work adds only the selected invocation and one result-to-next-
decision transition; it does not require a command-catalogue lookup or a second
startup/report pass.

## Retained owners

- Workspace owns bounded removal of recognized package-managed state.
- Planning owns durable work status and completion transitions.
- Memory owns explicit durable records and reads.
- Verification owns process proof and the `complete` claim boundary.
- External modules may own bounded worker execution and structured evidence;
  declared effects reconcile directly into the parent source owner before the
  next decision is compiled.
- The reducer owns only normalization, conflict resolution, decision identity,
  action selection, and claim intersection.

Research, session adaptation, provider transports, IDE adapters, generated
non-Python clients, and offline no-runtime operation are not v1 product
surfaces. Explicitly enabled local maintainer session logging remains diagnostic
instrumentation rather than a decision or operation surface. Other capabilities
may be proposed later through a source owner and the public module seam; none is
silently retained for 1.x compatibility.
