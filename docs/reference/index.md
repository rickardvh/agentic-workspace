# Reference Index

Start with the [main AW skill](../../.agentic-workspace/skills/workspace-startup/SKILL.md)
and [everyday use](../everyday-use.md). Reference pages answer exact questions;
they are not a command workflow. Generated pages describe their named contracts,
which may be current public declarations, source-maintenance data or historical
representations. Schema presence never establishes current native support.

## Current native and release reference

- [Native CLI catalogue](cli-catalogue.md): `start`, `invoke`, `resources`, `worker` and their flags, generated from the executable's `native_cli` declaration in `source_decision_contract.json`.
- [Native tool map](../package/commands.md): use current owner requests/actions, including repeated `--changed` on `start`; obtain detail through supported projections and returned references.
- [Shared Rust authority](../architecture/shared-rust-core.md): current typed request/action/result boundaries and thin native/JSON/Python/Node transport.
- [Installation and adoption limits](../agentic-workspace-install.md): exact preview versus support-bearing receipts and native bootstrap limitations.
- [Surface catalogue](installed-surface-catalogue.md): source-maintenance footprint/profile inventory, not an available native lifecycle command.
- [Support-bearing install projection](support-bearing-install.md): applies only to its named immutable stable release; not a receipt for an unpublished preview.

Use the installed executable's `--help` and current owner responses for live
support. Historical `implement`, `report`, nested/module commands, `--select` and
`--verbose` are not native affordances.
