These are bounded author behaviour exercises for the #3758 stack. Each reader
starts with a fresh context, an ordinary task and that layer's guidance and native
executable. They do not review or approve the implementation. Independent review,
hosted checks and #3191's natural lifetime payoff remain separate.

The environment is Windows PowerShell with the locked workspace debug executable
and an OpenAI Codex internal fresh-context agent. The tool does not expose a model
revision or token/currency totals; none are inferred from Assignment preferences.
No external service is contacted. Fixtures live in one AW-owned disposable task
scratch container, not another product checkout. Native calls, semantic results
and failures are recorded by the reader. Call counts include failures and help.
