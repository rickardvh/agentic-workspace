## Reused aggregate journeys

The pre-integration check reuses the full Rust workspace suite and selected
existing public owner journeys for skill/bootstrap and tree-only reading,
carried answers/actions, direct-work measurement, Planning lifetime, repository
posture, sealed process/bridge handoff and replacement, patch integration,
advisory capture and whole-lesson promotion, two adaptation destinations and
claim/reviewer boundaries. Existing native owner tests retain the failure classes;
this selection adds no permanent mega-suite, telemetry store or CI job.

The same checks are inputs for #2909 on the eventual exact integration subject.
Release-scale artifact/platform/public-byte checks belong to the existing
preview/admission path. A green source run neither admits an artefact nor proves
a paid-provider execution occurred. A failed owner case must be fixed at that
owner, never inside an aggregate wrapper.
