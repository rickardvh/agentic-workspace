# Planning activation custody

TypeScript new-plan activation preserves an existing local selector or receipt before writing a candidate. With absent carriers, selection goes through the existing owner-select admission boundary and exclusive creation. A failed selection preserves its draft and reports the actual refusal; state registration does not proceed. No byte-check-based rollback deletion is attempted.

The historical TypeScript scaffold currently lacks the current canonical owner fields required by owner-select. Ordinary activation therefore reports `owner-not-selectable` and retains an unselected draft. Existing valid owners still have the independently tested absent-carrier acquisition route. This correction does not claim current Planning creation is complete.

Next owner work belongs to #2970/#2986/#2987: expose a bounded agent-authored creation request through Rust, validate its canonical Planning identity, scope, constraints, dependencies, stops and proof obligations, and atomically acquire an absent owner before existing selection admission. Reuse the canonical schema and existing Planning reconciliation/attempt primitives. There is no current Rust creation constructor to forward this obsolete TypeScript scaffold into; adding another TypeScript constructor would recreate the semantic split.

Existing local selections without native reconciliation custody remain readable source authority, but `continue-selected` is only task applicability. #3001 owns exact source-owner release/current producer admission and destination acceptance before first mutation; #2984 owns preserving the former representation until that reconciliation is complete. An old receipt kind, matching digest or owner-name string alone cannot supply transfer authority. No generic ownership database or second Planning representation is required.

Focused proof: tests/test_planning_selection_custody.py covers native retained custody versus actual public TypeScript activation, source/state preservation, explicit invalid-scaffold refusal, valid existing-owner acquisition, collision and exclusive-creation races. The first run passed 16 existing cases and failed both new expectations because the historical scaffold was not selectable. The corrected evidence preserves that limitation; 18 cases pass. Independent acceptance and the complete native returned/integration-pending vertical remain outstanding.
