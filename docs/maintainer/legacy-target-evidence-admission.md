# Legacy target evidence admission

The historical producer-store reader cannot establish target quality from editable receipt/index shape. Its five families share this limitation:

| Family | Missing authority at this legacy boundary |
| --- | --- |
| `aw-proof` | Current producer publication, task/assignment binding and causal target responsibility |
| `human-review` | Authenticated current judgment and exact target/claim binding |
| `retry-outcome` | Admitted current retry lifecycle and causal outcome binding |
| `handoff-outcome` | Admitted current return/integration lifecycle and causal outcome binding |
| `closeout-outcome` | Current owner completion/evidence admission and causal outcome binding |

The loader still diagnoses malformed, missing, stale and mismatched records, but a matching editable index never upgrades them into quality authority. Direct caller-supplied trusted-record dictionaries cannot bypass this boundary. Previously retained family records remain visible as uncertainty on reread and cannot route an assignment. Local-operator observations retain their existing distinct contract.

The ordinary legacy causal helper preserves its observation, target context and attribution in the existing source store, returning `preserved-unproven` with `target-quality-stronger-owner-required`. A causal classification is not publication custody or independently admitted lifecycle evidence. The correction does not create a replacement store, authenticate historical records, or migrate legacy producer writes into a native custody owner.

Actual native command execution can still publish current reusable Verification evidence. That proof alone supplies neither a delegation target nor its causal responsibility. Native authenticated review and shared causal/lifecycle reducers are unchanged. Positive target learning requires their current source-owned binding; it remains implementation work under #2209/#2334/#3001. These regressions ratchet the boundary under #2909 without closing those owners.
