# Prepare a delegation

State the bounded outcome and what remains with the orchestrator. Separate the
reason delegation helps from target feasibility. After delegation is relevant,
read current task requirements and Assignment alternatives; provide only the
requested result/proof classes, scope judgments and comparative evidence.
Unavailable, ineligible, tied and unresolved alternatives remain explicit.

```agentic-owner-reference
{"kind":"request","owner":"assignment","id":"assignment/comparative-assessment"}
```

The current owner admits a binding target and transport. A semantic answer cannot
make an ineligible target eligible or permit launch. Once bound, stop reranking:
follow the current assignment or its exact recovery route. If no constructible
eligible path exists, preserve that gap; use local work only if currently admitted.

Prepare [the frontier](frontier.md), then carry the owner's exact sealed export or
dispatch. An optional method supplies no transport permission:

```agentic-owner-reference
{"kind":"action","owner":"delegation","id":"delegation.dispatch"}
```
