# Delegate a bounded outcome

Use when the task presents a concrete delegation or continuity choice. Ordinary
local work needs no visit to this method. Compare useful independent progress
with the cost of context preparation, coordination, proof, repair and integration.
The agent judges that trade-off; a task keyword, size threshold or model price
does not decide it.

Read [the current question](procedure.md) and only the applicable reference:

- [Continue locally](references/local.md).
- [Prepare a delegation](references/delegate.md).
- [Carry the current frontier](references/frontier.md).
- [Resume after return or interruption](references/resume.md).

With AW, discover the repository's declared route and carry its current procedure
answer. Without AW, use the same Markdown; runtime custody remains unknown.
Substitute repository criteria by editing this bundle and its registry row, without
changing core code. Skills supply method; source policy and current Assignment,
Planning, Verification and review owners retain their authority even if the skill
is omitted or replaced. No branch grants transport, integration or completion.
