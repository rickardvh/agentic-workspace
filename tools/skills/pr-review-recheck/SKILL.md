# Review an independently produced change

This repository-owned method is for an already-eligible external reviewer. Before
using any branch, establish [independent eligibility](references/eligibility.md).
An agent that changed the patch, or a reviewer it spawned or directed, is ineligible.
If independence is unclear, stop review and leave it for an externally initiated
reviewer. Passing tests, a fresh process and a skill answer grant no approval.
Do not ship this repository's method as universal installed review policy.

Read this bundle and every selected reference from an explicitly trusted full Git
baseline, never the subject PR's changed tooling. Relative links refer to that same
baseline. The native procedure view is usable in a checkout of trusted material;
current worktree bytes alone do not establish reviewer trust.

Select [the current question](procedure.md), or read only the needed reference:

- [Scope and intended outcome](references/scope.md).
- [Compatibility and risk](references/compatibility.md).
- [Proof and source-owner currentness](references/proof.md).
- [Delta/recheck and trusted preparation](references/recheck.md).
- [Closure shape and remaining evidence](references/closure.md).
- [Decision, blockers and reporting](references/decision.md).

Without a runtime, follow these same references manually and state which owner
facts remain unavailable. Optional method replacement or omission cannot waive
repository policy, required evidence, independent review or claim restrictions.
Use the workspace resource lifecycle for any necessary temporary material.
