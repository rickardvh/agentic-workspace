# Planning Assurance Delegation

Use this skill only before a canonical assignment exists, and only when the
assignment owner requests unresolved risk, proof, ambiguity, or capability
input. A binding assignment ends this skill's authority.

## Ownership

This skill owns pre-assignment assessment, not target selection, action
permission, handoff, dispatch, or returned-result handling. It contributes
bounded evidence to the canonical assignment decision and returns control to
that owner.

## Procedure

1. Read the compact current decision and the exact unresolved inputs named by
   the assignment owner.
2. Assess only those inputs: task risk, ambiguity, required proof, hard
   eligibility, and capability evidence. Keep observed evidence separate from
   preference or predicted efficiency.
3. Report eligible, ineligible, tied, or insufficient-evidence findings with
   provenance and uncertainty. Ask for human input only when the canonical
   decision identifies a human-owned ambiguity.
4. Return the assessment to the canonical assignment owner. Do not choose a
   target, record a substitute assignment, or render a worker handoff.

## Post-Assignment Boundary

If assignment identity and revision are already binding, stop using this skill.
Selected-current-target work stays on the ordinary direct path. A binding
non-local assignment routes to `planning-orchestrator-workflow`; cost,
availability, or capability preference cannot reopen target choice.
