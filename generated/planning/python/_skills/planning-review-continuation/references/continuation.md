# Route a justified finding to its owner

Recheck that a selected finding is current, supported and concrete, with a clear
source class and an explicit promotion trigger. Do not promote every finding.
Measured friction, repeated failure or explicit maintainer direction may justify
planned work; mere analysis does not automatically create an execution obligation.
If the case is weak, defer or dismiss without a new backlog or standing suppression.

Choose the strongest appropriate home: ordinary source repair for enforceable defects,
canonical guidance or Memory for reusable knowledge, and Planning only for unfinished
execution needing custody. Irrelevant or already-resolved findings need no plan.
Use workspace correction for source disposition and `planning-work` for existing
relation, bounded intake and creation/update. Preserve source classification and
the reason for activation; do not duplicate work shaping or closeout here.

```agentic-owner-reference
{"kind":"request","owner":"planning","id":"planning/update/v1"}
```

This exact reference may be missing when no current owner exists; use the current
Planning creation decision if warranted, rather than fabricating an update. Follow
the returned request/action and inspect effect plus continuation. Findings remain
distinct from proof sufficiency, independent acceptance, merge authority and intent
satisfaction. Report promoted, deferred/dismissed findings and actual owner effects.
