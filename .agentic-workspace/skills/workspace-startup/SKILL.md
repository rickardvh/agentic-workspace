# Start ordinary work

Read the task and applicable repository instructions. Obtain current AW context
once at session entry, and again if its dependencies change; reuse a current
answer. Follow [ordinary use](references/ordinary.md) for the configured command.

If AW reports setup or refresh needing attention, follow the
[setup procedure](../workspace-setup-jumpstart/SKILL.md), then return to the task.
Otherwise work directly. Load only the [procedure](procedure.md) useful to the
concern encountered. Skills guide method; they do not grant permission or proof.

Use [exact owner actions](references/owners.md) for managed changes. If the runtime
is unavailable, [read relevant sources](references/unavailable.md); preserve
managed state and report unknown current facts. Retain unfinished work or lessons
only when they have [future value](references/reconcile.md).
