# Use the current proof continuation

After a native check, keep the observed process result and original tested
subject, independently of later admission or publication. The existing run
carrier and `observation.reference` retain an authenticated completed result.
Normal Verification consumption assesses its current subject/runtime/strategy
coverage without launching the command again. `source_current` describes the
return observation; current use is assessed separately. A live checkout's equal
launch/return hashes do not establish an immutable snapshot or exclude transient
mutation. Only the isolated executor supplies its snapshot guarantee.

Failed, skipped, timed out or incomplete execution remains limited evidence.
If continuation is missing, preserve the effect and use [exact recovery](recovery.md)
only for a needed fact. A historical pass remains a pass on its observed subject;
it is not automatically current proof, native publication or task completion.

Use other evidence with its actual provenance when source policy permits it.
Native admission uses the owner's exact request; terminal output cannot be
fabricated into native custody. Judge the actual outcome through
[claim interpretation](claim.md), without a mandatory final AW acknowledgement.
