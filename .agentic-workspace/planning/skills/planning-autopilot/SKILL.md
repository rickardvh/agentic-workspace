# Bounded Planning Continuation

The former autopilot host command is not part of the native public interface. This skill supplies procedure for an already authorized agent session; it does not provide a scheduler, executor launcher or final-response admission service.

1. Read repository instructions and resolve `agentic-workspace start --target <repo> --task "<task>" --format json` when current Planning facts are needed.
2. Inspect the selected owner's bounded outcome, current restrictions and required continuation. Reconcile ambiguous scope before implementation.
3. Perform the authorized slice using ordinary tools and current owner requests. Follow Assignment restrictions when selecting an executor; this skill does not authorize delegation.
4. Run the narrowest sufficient validation, then reconcile progress and continuation through exact owner requests and actions.
5. Continue while the user's authorized objective has safe remaining work. Stop for completion, a real blocker, or user direction; do not widen scope because adjacent work is visible.

Report the bounded result, evidence, unresolved obligations and next owner. Separate successful validation from issue completion and larger intent satisfaction. Preserve independent review and source-reconciliation boundaries.
