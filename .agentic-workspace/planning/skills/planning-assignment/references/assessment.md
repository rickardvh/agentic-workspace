# Supply unresolved assessment

For a justified delegate choice, state the independent bounded outcome and what
stays local. Separate why delegation helps from whether any target is currently
eligible. Request current task requirements and Assignment assessment; do not
nominate or authorize a target in the method itself.

```agentic-owner-reference
{"kind":"request","owner":"assignment","id":"assignment/task-requirements"}
```

Before a binding assignment, read only the unresolved risk, ambiguity, proof,
result-class, capability or feasibility inputs requested by the current owner.
Separate observed evidence from preference and predicted efficiency. Supply bounded
findings with provenance and uncertainty. Eligible, ineligible, tied and insufficient
evidence are honest outcomes; only the owner admits a resulting target binding.
No fit or unavailable transport remains an explicit owner gap; local continuation
requires current admission when binding policy applies.

Do not manufacture a substitute assignment or render a handoff. Ask a human only
for an unresolved human-owned decision. Once a binding assignment exists, this
pre-assignment method ends; follow [the binding](binding.md) without reranking.
