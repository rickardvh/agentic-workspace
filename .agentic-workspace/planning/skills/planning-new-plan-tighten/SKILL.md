# Planning New Plan Tighten

Use this skill when work needs durable Planning custody and the current record lacks concrete execution detail. Keep direct work direct.

1. Resolve `agentic-workspace start --target . --task "<task>" --format json` and inspect current Planning detail.
2. Use its exact selection or creation request for the intended owner. Preserve existing issue and parent relationships; do not create a second plan for the same work.
3. State the bounded outcome, acceptance evidence, negative requirements and required continuation through the returned request fields. For prep-only work, preserve that scope rather than manufacturing implementation readiness.
4. Execute only an exact owner-returned action with `invoke`. Read the effect result and current continuation before proceeding.
5. Tighten unresolved semantic requirements through current owner requests. A scaffold, successful write or quiet owner does not establish implementation or completion authority.

Do not copy legacy templates into custom owner shapes, hand-edit managed state, or reconstruct request identity from an earlier plan. Preserve current source, policy, Assignment and Verification restrictions.
