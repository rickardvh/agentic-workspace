# Agentic Workspace procedure pointer

Start or resume work with
`.agentic-workspace/skills/workspace-startup/SKILL.md`. It explains when available
sources suffice and when the next action needs current AW information.

This compatibility pointer adds no permission or procedure. Repository/local
instructions and configuration supply policy; the responsible components maintain
state, evidence and supported operations. If AW cannot run, follow the same skill's
source-reading path and leave unobserved runtime facts unknown.
