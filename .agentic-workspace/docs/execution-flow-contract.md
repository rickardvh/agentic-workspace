# Execution and reconciliation

Human instructions and repository policy own the intended outcome and constraints. The acting agent chooses bounded means within that authority. Skills teach procedure; native owners resolve exact current information, requests and effects.

Read the configured startup skill. When current state matters, use `agentic-workspace start --target . --task "<task>" --format json`, adding known changed paths. Follow relevant current owner requests and execute only an exact returned action with `invoke`.

Planning participates when work needs durable execution custody, Assignment when current policy requires an execution choice, Memory when knowledge prevents rediscovery, and Verification when evidence or claim boundaries need resolution. Do not turn these owners into mandatory phases for direct work.

Keep original intent, the bounded slice, negative requirements and required continuation distinct. A local effect succeeding, validation passing, an issue being complete and the larger intent being satisfied are separate observations.

After work, reconcile only affected owners. Preserve unresolved source admissions and reviewer obligations. Do not edit interpreted owner state or advance trust revisions merely to make the current query quiet. Report validation and material limitations without treating process success as completion authority.
