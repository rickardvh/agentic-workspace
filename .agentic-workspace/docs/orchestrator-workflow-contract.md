# Assignment custody reference

The native Assignment owner determines role, target relation, current identity,
revision and permitted effects. A selected current target stays on direct work.
A binding non-local assignment forbids local implementation of the worker slice;
unavailable transport does not change that restriction. Only a current admitted
Assignment transition changes the binding.

Use the narrow [Assignment method](../planning/skills/planning-assignment/SKILL.md)
for assessment, binding, manual carriage, return or recovery. The orchestrator
retains intent, decomposition, admission, integration, proof interpretation and
closeout custody. Workers cannot widen scope or admit their own returns.

[Planning work](../planning/skills/planning-work/SKILL.md) carries unfinished work;
[closeout](../planning/skills/planning-closeout-trust/SKILL.md) distinguishes proof,
intent and completion. These sources replace the former duplicate phase recipe.
Missing runtime permits source reading only, with current custody unknown and
managed state preserved. Optional procedure grants no authority.
