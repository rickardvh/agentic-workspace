# Compact current-owner detail

The native `start` command returns a compact operating decision by default. Public command and option declarations belong to `source_decision_contract.json`; legacy selected-output envelopes are not the current CLI contract.

Use `agentic-workspace start --target . --task "<task>" --format json` for current information. Read only relevant exact references from `detail_refs`. Carry the same target, task and changed paths when resolving a reference with `--reference`; carried projection clients can supply their returned carriage through `--input`.

`--projection full` is available for deliberate broad inspection. `--projection carried` provides a model-facing view and disposable exact carriage for thin hosts. Neither projection changes ownership or admission.

Do not reconstruct a reference, reuse it for different work, or assume unchanged prose proves current admission. Source owners revalidate currentness. The prior defaults/proof/ownership selector model remains source-maintenance material and does not define executable public commands.
