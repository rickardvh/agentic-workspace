# Minimum operating model

Read repository instructions and the configured workspace-startup skill. Use ordinary judgment and keep direct work direct.

When exact current owner facts or effects matter:

```sh
agentic-workspace start --target . --task "<task>" --format json
```

Add known paths with repeated `--changed` arguments. Read relevant returned detail references, answer exact owner requests, and execute only exact admitted actions with `invoke`.

Planning owns active execution custody and continuation. Memory owns durable anti-rediscovery knowledge. Verification owns evidence and claim admission. Configuration and repository instructions own policy. Skills supply procedure without adding authority.

Load a specialized skill or domain only when it helps this task. No-signal work needs no replacement command, obligatory plan or broad state dump. Native unavailability leaves current runtime facts unknown; use the startup skill's repository-readable fallback.
