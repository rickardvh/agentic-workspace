# Knowledge disposition guidance

This source-repository reference supplies advisory examples. The installed
[startup skill](../skills/workspace-startup/SKILL.md#evidence-for-a-decision) owns
acquisition and sufficiency; the selected
[correction procedure](../skills/workspace-instruction-correction/SKILL.md) owns
routing to existing repair and retention destinations. This document is not a
second canonical workflow or a public host requirement.

Choose a durable home for its future decision value and actual authority, not
because knowledge passed through chat or appeared twice. An explicit authorized
requirement or decision can go directly to its proper owner on first occurrence.
Ordinary code, tests, configuration, docs and skills can be that home. Advisory
Memory and governing decisions keep their distinct admission and disposition
requirements. Planning is for execution continuity, not a mandatory staging area.
No lesson, no retention and already-current need no closure bookkeeping here.

## Refactoring facts worth retaining

Non-obvious compatibility behavior, domain rationale, dependency or migration
constraints, and unsafe-to-remove paths can justify concise advisory context when
future work would otherwise reconstruct it. Preserve the accepted conclusion,
source identity, relevant scope, rationale and stale dependencies. A source
reference or current hash does not establish correctness or deciding authority.
Do not copy transcripts, raw test output, execution chatter or unverified guesses.

For example: importer v1 emitted a trailing delimiter, so parser compatibility
still matters while v1 data is supported. Reference the current compatibility
requirement and fixture; identify that support ending or the fixture being replaced
requires reconsideration. The note explains a constraint rather than granting
permission to change it. Preserve this rationale if a stronger receiving source
absorbs only part of the lesson.

When a currently authorized source repair is possible, complete and validate it
instead of merely retaining a warning. Reconcile affected guidance afterward via
its owner, narrowing or retiring advice only when justified. Memory disposition
may suppress selection through metadata while retaining the original note; do not
promise deletion or completed promotion without supported admission. A changed
receiving source can make the earlier disposition need reconsideration.
