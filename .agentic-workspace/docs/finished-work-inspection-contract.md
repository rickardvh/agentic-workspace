# Inspecting finished work

Archived Planning records and their admitted evidence preserve bounded closeout decisions. They are recorded assertions; current owner admission determines whether a claim is still valid.

For a current question about landed work, resolve `agentic-workspace start --target . --task "<task>" --format json` and inspect the relevant Planning references. Read exact archive/evidence references rather than scanning all history. Current external issue observations can contradict an earlier claim but cannot replace Planning or Verification authority.

Distinguish completed implementation, validation, issue satisfaction and larger intent. Missing evidence remains unknown. If current evidence reopens a material gap, reconcile the affected owner and its required continuation. Do not silently create a new backlog, rewrite historical evidence, or infer completion from an empty current selection.
