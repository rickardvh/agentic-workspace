# Memory Router

Use when the task needs relevant saved advice. Read current `advisory_context`
if it was already delivered. Otherwise use the repository's configured AW
invocation with `start --target . --task "<task>"` and repeated `--changed <path>`
arguments. Answer returned applicability questions from the actual task; do not
read the whole Memory corpus.

Consume the current `advisory_context`: selected lessons arrive with the current result. Larger selected bodies are carried by the active proof procedure or selected owner detail; do not repeat a Memory-specific read merely to retrieve a delivered lesson. The manifest's path and semantic-route selectors determine the bounded selection; recognizable source bytes confer no factual or mutation authority.

No-match stays quiet. Missing, contradicted or stale material stays visible as reconciliation rather than being silently adopted. For a disposition use [Memory Hygiene](../memory-hygiene/SKILL.md). If routing itself needs correction and no current native request offers it, preserve the concrete missed or excessive selection with the existing owner; do not create a parallel index or use the former host as authority.
