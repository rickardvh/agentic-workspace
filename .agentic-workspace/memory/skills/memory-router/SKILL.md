# Memory Router

Use the repository adapter's configured AW invocation with `start --target . --task "<task>" --format json` and repeated `--changed <path>` arguments. Follow the decision packet and owner-returned applicability questions.

Read only `memory.selected_notes` through the exact current requests in `memory.requests`. Submit requests through `start --input <request.json>` with unchanged context. The manifest's path and semantic-route selectors determine the bounded selection; recognizable source bytes confer no factual or mutation authority.

No-match stays quiet. Missing, contradicted or stale material stays visible as reconciliation rather than being silently adopted. For a disposition use [Memory Hygiene](../memory-hygiene/SKILL.md). If routing itself needs correction and no current native request offers it, preserve the concrete missed or excessive selection with the existing owner; do not create a parallel index or use the former host as authority.
