# Use advice and decide what is worth keeping

Use when selected advice or a useful conclusion needs attention. Read already
delivered `advisory_context`; obtain current selection through the configured AW
`start --target . --task "<task>"` with known changed paths only when needed.
A no-match result needs no further Memory work or saved record.

Before the next action or claim that this advice could affect, compare it with
the current governing source and other already-relevant facts. When their
relationship supports a correction or legitimate alternatives, use the
[related-finding method](../../../skills/workspace-instruction-correction/references/related.md)
to choose one bounded action within current authority. Explain which decision
changes; a warning alone is not the outcome. This does not select an audit or
require looking for other notes.

After a verified correction, reassess the advice that depended on the former
condition before claiming the affected work complete. Matched dependency hashes
do not establish that a compensating method remains useful. Use the current
disposition request for obsolete advice, preserve independent rationale and
evidence, then confirm fresh selection. No further record is needed for advice
that still applies unchanged. An unavailable owner leaves disposition unresolved.

Keep the useful conclusion with its smallest existing owner. Planning owns execution continuity, Verification owns proof, and repository decisions retain their deciding authority. A passing test does not establish a durable lesson or authorize a Memory write.

For a selected note or advisory fact, follow [Memory Hygiene](../memory-hygiene/SKILL.md). Current native disposition requests preserve external source ownership and need an exact bounded domain answer under current task authority. Promotion additionally needs current receiving-owner admission of the complete lesson. If that admission is unavailable, preserve advisory value or expose reconciliation.

Do not create a record just to show consultation, archive the conversation, or revive retired summary/report/promotion commands. Report the selected source, useful lesson or no-signal result, and unresolved owner only when those facts help continuation.
