# Memory Consultation And Residue

Use the configured AW `start --target . --task "<task>" --format json` and known changed paths. Follow the decision packet. Inspect only current selected notes through `memory.requests`; no-match needs no further Memory work.

Keep the useful conclusion with its smallest existing owner. Planning owns execution continuity, Verification owns proof, and repository decisions retain their deciding authority. A passing test does not establish a durable lesson or authorize a Memory write.

For a selected note or advisory fact, follow [Memory Hygiene](../memory-hygiene/SKILL.md). Current native disposition requests preserve external source ownership and need an exact bounded human answer. Promotion additionally needs current receiving-owner admission of the complete lesson. If that admission is unavailable, preserve advisory value or expose reconciliation.

Do not create a record just to show consultation, archive the conversation, or revive retired summary/report/promotion commands. Report the selected source, useful lesson or no-signal result, and unresolved owner only when those facts help continuation.
