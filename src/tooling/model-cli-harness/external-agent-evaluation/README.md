# Historical external-agent evidence

This directory preserves dated observations, sample records and their historical
contracts. `external_agent_evaluation_lane.py` reads them for archival consistency
and existing completion-cost reports. Its former operating-loop and assignment
expectations are not current product acceptance criteria.

For current installed execution and independent outcome checks, use the
[consumer harness guide](../../../../docs/maintainer/model-cli-dogfooding-harness.md).
The retired suites and research executor are available in Git history; they must
not select a package version or count as live current evidence.
