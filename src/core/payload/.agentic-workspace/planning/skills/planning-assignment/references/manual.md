# Carry a sealed manual packet

Use only the current owner's exported sealed Assignment packet when manual
transport is admitted. Disabled transport permits no handoff. Export does not
execute; a returned packet remains unproven until current native admission.

The existing configured `worker --input <json> --format json` primitive presents
an exact packet. A thin host holds the packet and gives the worker the `view` from
`{action: "entry", packet}`. Expand every required lazy input with
`{action: "expand", packet, reference: <detail_ref>}` before assigned work. These
are captured bytes, not fresh repository admission or permission to widen scope.

Return only new `summary`, `changed_paths`, `patch`, `stop_conditions_hit` and,
when needed, `result_delivery` using `{action: "return", packet, material}`.
Submit the exact resulting reentry to current `start`. Matching seals, import or
presentation do not establish acceptance, integration, proof or closure.

Worker helpers report only observed serialized presentation/packet bytes and their
own writes. Host-injected skills, semantic turns, user steering, repairs and elapsed
time are unknown unless actually observed; unknown cost is not zero.
