# Shape and continue Planning work

Use at the start of new work when decomposition or durable continuity would
materially improve execution, and when a later session needs the agreed outcome
and remaining steps. Reuse sufficient existing task records; create/select native
Planning custody when intended outcome, constraints, dependencies or unfinished
follow-through otherwise lack an adequate home. Planning maintains those records
and their relationships. A `direct` native status means no current owner
obligation, not that a plan is unnecessary. Explicitly relate an existing owner
to this task before using it; an unrelated remembered selection remains inert.
Simple self-contained work needs no plan or extra command.

Use [the current question](procedure.md) or its same-source links directly:

- [Relate the current request to existing work](references/intake.md).
- [Bound the outcome and its dependencies](references/structure.md).
- [Save progress and resume from the saved record](references/continuity.md).

Use the configured native invocation and exact owner requests/actions. Without it,
read only relevant sources; current custody is unknown and managed state stays
preserved. Optional procedure supplies no assignment, proof or completion authority.
