# Judge the bounded claim

Select evidence for the actual task, slice, lane or epic claim. Read the selected
protocol purpose, expected observations, escalation and review aids when judging
adequacy. Baseline and escalation/de-escalation permissions come from Verification.
Source commands and numeric ordering do not decide that judgment.

Classify failed, warning, skipped, retried, crashed, unavailable or incomplete
results honestly. A selected check's exit zero is not intent satisfaction.
Measurement admission comes from the native owner and its current private receipt,
not labels or helper arithmetic. Semantic protocol/domain applicability comes
from exact current judgments; never match task words or reinterpret the manifest.

Finish when the requested outcome and real requirements have adequate current
evidence. AW's missing certificate supplies neither prohibition nor satisfaction.
An optional publication or Memory failure is no reason for another check, status
write or final handshake. Preserve actual failing checks, incomplete acceptance,
required native producers, protected effects and independent review.

`verification_context.optional_judgment` is available when a native semantic
record would help. Explicit `strict_closeout=true` requires its native judgment,
even without a matching protocol; then use `verification_context.next_step`.
With current reentry, supply only the sufficiency judgment/reason and inspect the
bounded question before confirming. Required source reconciliation and separate
reviewer custody keep their own scope. A source-intent pointer alone adds no
certificate requirement. Native record availability does not decide task success.

When using native claim judgment, keep known candidate observations separate from
selected supporting references. The returned request carries `candidate_refs`
through confirmation. Its `evidence_dispositions` accepts a reasoned materiality
or supported supersession judgment for a failed observation. An optional command
failure alone creates no task requirement; a genuinely contradictory result still
matters. A required check cannot be dismissed as immaterial. A correction must
have current source/command/subject coverage; retain the original failure. This
is a selected evidence judgment, not another form required for ordinary tasks.

Distinguish implementation complete, ready for independent review, review
accepted, authorised to merge and released. Adequate implementation can reach its
review stage without claiming approval or release readiness.

Run the lowest sufficient current proof selected for the changed behavior and
requested outcome. State the failure risks covered, existing evidence reused,
any permanent-test retention decision, and the observation that lets proof stop.
No new permanent test is needed when current coverage is sufficient. Broaden only
for a named unresolved risk and say what additional observation would settle it.
Distinguish validation,
issue completion, intent satisfaction and total operating cost. Reconcile actionable
remaining gaps through their existing owner; retain only knowledge that prevents
rediscovery. Do not infer lane completion from a local check or self-review.
