# Choose the smallest resource

Use one task container below `.agentic-workspace/local/scratch/` for temporary
JSON, notes and experiments. Build output stays in build-tool locations; repositories
stay outside AW state. A concrete checkout conflict, destructive validation or
transport requirement may justify isolation; parallel convenience alone does not.
Read current repository/local instructions. Do not clone to evade worktree policy.
If no resource is needed, continue directly without a resource call.
