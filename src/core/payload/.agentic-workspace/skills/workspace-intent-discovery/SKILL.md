# Clarify the outcome and size the work

Keep clear direct work direct. Use this method when plausible interpretations
would lead to different outcomes, or several steps need a plan for later sessions.
Select the
[current question](procedure.md), or read the [intent method](references/intent.md)
and [shape vocabulary](references/shape.md) as needed. Read cheap named evidence
before asking for missing human judgment. Current owner decisions, clarification
policy and restrictions remain binding. Stop when the next step has enough agreed
intent to proceed safely; record remaining uncertainty if it still affects later work.
