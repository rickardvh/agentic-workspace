# Clarify the outcome and size the work

Use this method when plausible interpretations could materially change the
requested outcome, or unfinished work may need a plan to preserve intent across
sessions. Clear, self-contained work needs no clarification or Planning record.
Read available task and repository evidence before asking a human to repeat it.
Select the [current question](procedure.md), or read the
[intent method](references/intent.md) and [work-shape guidance](references/shape.md)
only as needed. Keep current owner decisions, clarification policy and restrictions.
Stop when the next step has enough supported intent to proceed; preserve only
uncertainty that could change later work.
