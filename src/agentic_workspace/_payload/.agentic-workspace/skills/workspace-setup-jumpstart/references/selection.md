## Current native method

Select `configuration_write.behavior_request` from current native context and supply
the relevant `concern`: `instructions`, `diagnostics`, `assignment`, `modules`,
`invocation`, or `preferences`. Select by the human outcome, not task-word matching.
Carry affected-owner judgments as the exact current request set; never manufacture
absent edit requests. Follow [shared owner carriage](../../workspace-startup/references/owners.md).

Native admission checks source, policy and work currentness. The writer attaches
current affected-owner observations after a supported write. A known failure to
launch means no owner entry; once the process may have started, preserve effect
uncertainty and use current owner recovery.

When the concern is already settled or has no durable value, do no work and
retain nothing. A configured command prefix such as `uv run agentic-workspace`
is an agent-facing invocation; do not pass it as one executable filename.
